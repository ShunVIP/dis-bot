# Raid schedule

`/рейд` строит календарь с понедельника по воскресенье в московском времени.
Можно передать любую дату нужной недели: `ДД.ММ`, `ДД.ММ.ГГГГ` или
`ГГГГ-ММ-ДД`.

Опорная дата цикла — 30.07.2026:

- Люси: выходной → работа до 23:00 → удалёнка 09:00–21:00 → удалёнка
  09:00–21:00.
- Рейми: смена 24 часа в 112 → выходной → выходной → отсыпной перед сменой.

Оба цикла повторяются каждые четыре дня. День подходит для рейда, когда Рейми
на выходном, а Люси на выходном либо на удалёнке. При удалёнке календарь
показывает окно после 21:00 МСК.

Команда доступна напрямую и через игровой раздел `/команды`.
