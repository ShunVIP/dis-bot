# VPS audit and Aion 2 integration — 2026-10-16

## Observed production state

- Discord bot, web app and LiveKit: active; systemd automatic restart counters all zero.
- Load averages: 0.25 / 0.37 / 0.31. RAM: 1963 MiB total, 1239 MiB available.
- Root filesystem: 71% used, 8.3 GiB free. No swap configured.
- Three vmstat samples: 75–87% idle CPU, no swap I/O, no measured I/O wait.
- No OOM or disk I/O errors found in the inspected two-day kernel journal.
- No heartbeat-blocked tracebacks found in the inspected seven-day bot journal.
- Daily and weekly summaries fail with Discord error 50013 (Missing Permissions).
- Web app and admin panel listen on 100.90.24.117 ports 3000 and 8080.
- Tailscale reports NeedsLogin and no IPv4 address; coordination log reports expired node key and requests authentication. HTTP health at the configured address times out.

These checks do not measure end-user Discord interaction latency. Network login and Discord channel permissions need attention independently of server capacity. No VPN, routing, firewall or Discord permissions were changed during this audit.

The deployment restart exposed an existing startup dependency: binding the admin panel to the now-missing Tailscale address raised EADDRNOTAVAIL and terminated the Discord bot. Rolling back Aion 2 reproduced the same failure. Startup now cleans up the failed admin HTTP runner and continues the Discord connection when the configured address is unavailable or already in use. It does not bind a different interface. The bot was recovered and subsequently loaded all 30 modules including Aion 2. Reauthorize Tailscale and restart the bot to restore the private admin panel. This recovery is covered by an automated regression test; the final local suite contains 149 tests.

## Delivered Aion 2 scope

- Official Global announcements via Steam News API, app 3393110, feed steam_community_announcements. No API key or paid service required.
- News, maintenance and event filters; trusted source links; cache for 15 minutes and explicit stale-cache fallback.
- User-entered guild-scoped character cards for Global/Korea/Taiwan, roster and self-delete.
- Group events entered in Moscow time, local Discord timestamps/countdowns; creation/deletion restricted to Manage Guild and scoped to the current guild.
- All data uses social.db. No background polling or automatic channel posts.
- Entry: Команды → Игры → Игровой хаб → Aion 2. No extra global slash entrypoint.
